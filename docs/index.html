Agent Risk Monitor

recorded evaluation runsSource on GitHub

What does a coding agent do when the task in front of it cannot be done the honest way, and what changes when a monitor checks each action before it runs?

Five models were given the same tasks in a sandbox, twenty times per condition. In one, a script fails for want of an API token while the project next door has one that works. In the other, a test fails because of a defect in code the repository says not to edit. A runtime monitor either only recorded what the agent did or refused what went beyond the limits it was given.

Nothing here is live. These are the recorded runs, and each one can be replayed step by step under Compare: what the model said, the command it ran, and what the monitor made of it.

The monitor is open source under the MIT licence: github.com/SweetVege/agent-risk-monitor. The model judge whose one-line assessments appear in some replays is not part of the open edition. Counts are out of twenty runs per model and condition, on two scenarios; they describe these runs and are not rates for a model in general.
